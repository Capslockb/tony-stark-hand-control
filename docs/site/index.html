Control your PC with a hand wave.

Multi-camera hand tracking + 3D room mapping for PC control. Swipes drive keyboard navigation. Thumb-to-finger taps become clicks. Your hand is reconstructed in 3D, live. No cloud, no telemetry, no API keys — just a webcam and a Python interpreter.

Built for the way you actually use a computer

Most webcam hand trackers ship a virtual mouse and call it done. This one doesn't — because clicking the wrong thing is one pixel of slop away, and a "smart" cursor that keeps fighting the system focus is worse than no cursor. We do accessibility navigation: the same keyboard-navigation paradigm every OS already has, driven by your hand.

✋

1:1 hand tracking

Async MediaPipe worker + One-Euro filter + velocity predictor. Sub-frame latency, no GUI stutter, no inference on the main thread.

⌨

Accessibility-first input

Swipes send Tab / Shift+Tab / arrow keys. Thumb-to-index fires Enter. Thumb-to-middle fires the context-menu key. No mouse required.

🟢

Persistent focus overlay

Green border tracks the currently-focused UI element at 10 Hz. You always know exactly what your next gesture will activate.

📷

Up to 4 cameras

Auto-detects DSHOW / MSMF / ANY. Each runs MediaPipe in parallel. Per-cam enable/disable. Live-feed check auto-blacklists frozen cameras.

🧊

3D room mapping

Click-to-place anchors (walls, zones, hotspots, furniture). Triangulated live hand position. Save/load room_map.json. See your space.

🔒

Local-only by default

No telemetry. No analytics. The optional Ollama tab is off until you enable it. Everything else runs in-process, on your CPU, on your disk.

Up and running in 60 seconds

Clone, run the install wizard, launch. The wizard handles Python version checks, pip installs, and downloads the MediaPipe model. No admin rights required. Prebuilt binaries available for Windows (.exe) and Linux x86_64 (.tar.gz) if you'd rather skip the build. 

git clone https://github.com/Capslockb/tony-stark-hand-control.git
cd tony-stark-hand-control
python install_wizard.py
# Windows:
start_windows.bat
# Linux / macOS:
python3 tony_stark_hud_control.py

First launch is ~30 seconds (model download). After that: cold start is under 2 seconds.

Privacy isn't a feature, it's the default.

The hand-tracking pipeline never touches the network. Camera frames live in process memory and on your local disk. Calibration data and room maps are gitignored because they may be fingerprintable. No usage data, no error reports, no "phone home" check on launch.

The only optional network path is the Ollama tab — and it's off by default. It only sends frames to a cloud endpoint (or local server) after you explicitly enable it, configure the endpoint, paste an API key, and click Save.

# What this app does NOT do
✗ Phone home on launch
✗ Check for updates
✗ Report errors to a remote service
✗ Upload camera frames
✗ Track user identifiers
✗ Include ads, trackers, or third-party SDKs

# What it DOES do
✓ Run the hand-tracking pipeline on your CPU
✓ Save calibration to calibration.npz
✓ Save room map to room_map.json
✓ Optionally talk to 127.0.0.1:8080 or ollama.com (your choice, off by default)
