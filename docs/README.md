## Diagrams

The repository ships these SVG assets and their committed matplotlib generators:

- [images/architecture.svg](images/architecture.svg) — generated by [generate_architecture.py](generate_architecture.py)
- [images/gestures.svg](images/gestures.svg) — generated by [generate_gestures.py](generate_gestures.py)
- [images/3d_room.svg](images/3d_room.svg) — generated by [generate_3d_room.py](generate_3d_room.py)

Run the generators from the repository root:

```bash
python docs/generate_architecture.py
python docs/generate_gestures.py
python docs/generate_3d_room.py
```

Each script writes its corresponding file under `docs/images/`. Review the regenerated SVG diff before committing it; the diagrams are explanatory documentation and must remain consistent with the validated runtime behavior and known limitations.
