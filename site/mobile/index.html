    On a healthy build, hold an open palm until the engagement hold completes (0.6 seconds by default), then use swipes and brief fingertip taps. Current main has a live-loop regression tracked in Issue #16, so do not treat live behavior as currently validated.

Privacy: Camera-frame processing stays on-device in the core path. The repository does not add its own application analytics.

Quick answers

Does it cost anything?
The repository is MIT-licensed open source. Check any third-party service you configure separately for its own terms or costs.
Does it work without internet?
The core hand-tracking path is local after required model files are present. The installer may download the MediaPipe model, MediaPipe may send performance and utilization metrics, and optional Ollama-compatible snapshot inference can use a remote endpoint if you configure one.
What cameras work?
The application probes common OpenCV camera backends and can use multiple cameras, but device and driver behavior varies. Windows is the primary tested path. Live stereo coordinates remain experimental and are not measurement-grade while Issue #6 is open.
Does it drain my battery?
CPU, memory, and battery use depend on your cameras, drivers, resolution, camera count, platform, MediaPipe build, and tracking settings. Current main cannot provide a valid recurring end-to-end benchmark while Issue #16 is open.
Can I uninstall it?
For a source checkout, remove the checkout and any shortcut you created. Packaged-build cleanup depends on the package you installed; consult the release notes for that exact build rather than assuming identical behavior on every platform.

Current validation

main validation boundary

Windows is the primary tested path. Current live processing on main is blocked by the loop-rescheduling regression in Issue #16, and the repository CI matrix is tracked in Issue #3.

  • Do not use historical fixed test totals as current-branch validation.
  • Linux and macOS remain experimental source-install paths rather than feature-parity claims.
  • Live stereo reconstruction remains experimental pending the coordinate-convention correction in Issue #6.

Validation source: use the exact-commit GitHub Actions result and the current status of Issues #3, #6, and #16.
