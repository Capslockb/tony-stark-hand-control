Built for the way you actually use a computer

Most webcam hand trackers ship a virtual mouse and call it done. This one doesn't — because clicking the wrong thing is one pixel of slop away. We do accessibility navigation: the same keyboard-navigation paradigm every OS already has, driven by your hand.

✋

1:1 hand tracking

Async MediaPipe worker + One-Euro filter + velocity predictor. Sub-frame latency, no GUI stutter.

⌨

Accessibility-first input

Swipes send Tab / Shift+Tab / arrow keys. Thumb-to-index fires Enter. No mouse required.

🟢

Persistent focus overlay

Green border tracks the focused UI element at 10 Hz. You always know what your next gesture activates.

📷

Up to 4 cameras

Auto-detects DSHOW / MSMF. Each runs MediaPipe in parallel. Per-cam enable/disable.

🧊

3D room mapping

Click-to-place anchors (walls, zones, hotspots). Triangulated live hand position. Save/load room_map.json.

🔒

Local-only by default

No telemetry. No analytics. Everything runs in-process, on your CPU, on your disk.

Up and running in 60 seconds

Clone, run the install wizard, launch. The wizard handles Python, pip, and the MediaPipe model. No admin rights required. Prebuilt binaries for Windows (.exe) and Linux x86_64 (.tar.gz). 

git clone https://github.com/Capslockb/tony-stark-hand-control.git
cd tony-stark-hand-control
python install_wizard.py
# Windows:
start_windows.bat
# Linux / macOS:
python3 tony_stark_hud_control.py

First launch ~30s (model download). After that: cold start under 2s.

Privacy isn't a feature, it's the default.

The hand-tracking pipeline never touches the network. Camera frames live in process memory. No usage data, no error reports, no "phone home" check on launch.

The only optional network path is the Ollama tab — off by default. It only sends frames after you explicitly enable it.

Read the full security & disclosure policy →

# What this app does NOT do
✗ Phone home on launch
✗ Check for updates
✗ Report errors to a remote service
✗ Upload camera frames
✗ Track user identifiers
✗ Include ads, trackers, or third-party SDKs

# What it DOES do
✓ Run hand-tracking on your CPU
✓ Save calibration to calibration.npz
✓ Save room map to room_map.json
✓ Optionally talk to 127.0.0.1:8080 or ollama.com (off by default)

Release notes

Every shipped version, with the exact bugs fixed and features added. CHANGELOG.md

v1.0.32026-06-07release-readiness

Cross-platform install + test fixes. The app and installer now actually work on Linux, macOS, and headless systems.

Fixed

  • pyautogui import crashed on headless systems. Now lazy-loaded with a no-op stub shim.
  • Single-instance lock was a silent no-op on Linux/macOS. Now uses fcntl.flock on POSIX.
  • Selection overlay crashed on Linux Tk. Windows-only attr now guarded.
  • Test suite had hardcoded paths — now portable via __file__.

Added

  • This promo site (desktop + mobile) with the social card baked in.
  • ROADMAP.md with dated feature promises.

Test status: 70/71 pass on Linux under xvfb (1 fail is the real-webcam test).

v1.0.12026-06-04hotfix

Two crash bugs caught right after v1.0.0 shipped.

  • RoomMap.add() crashed on numpy 0-d arrays. Coerced via np.asarray(x).item().
  • flash_overlay() crashed with TclError: unknown color name "00FF00". Now auto-prepends #.

81/81 pass (77 main + 4 regression tests).

v1.0.02026-06-04initial release

The first public version. Multi-camera hand-tracking, accessibility navigation, 3D room mapping, all in one ~3,400-line Tkinter app.

  • Multi-camera (1-4) hand-tracking with async MediaPipe worker
  • One-Euro filter + velocity predictor for 1:1 tracking
  • Accessibility navigation: swipes → Tab / Shift+Tab, thumb-touches → Enter / right-click
  • Persistent green focus overlay (Win32 GetGUIThreadInfo at 10 Hz)
  • 3D triangulation + interactive matplotlib room map
  • Engage gesture: open palm held ~0.6 s
  • 5-tab Tkinter GUI + live performance HUD
  • 77-test suite, full docs
